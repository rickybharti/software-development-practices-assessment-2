# Software development practices - Assessment 2

A two-page static project demonstrating a local-first Git workflow.

Open `index.html` in a browser, then use the Home and About links.

## Repository evidence

- `main` contains the initial commit, home-page update, explicit feature merge,
  ignore rules, temporary change, revert, and command documentation.
- `feature` retains the feature commit for inspection.
- `.gitignore` excludes `*.log` and `temp/`.
- `git_commands.txt` explains the Git commands used and the publication procedure.

The single-PDF assignment report and local review evidence are kept separately.
No deployment or GitHub Actions workflow is configured in this repository.
